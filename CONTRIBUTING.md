# Contributing to Tachi

Thank you for your interest in Tachi.

**This project is currently not accepting external contributions.**

Tachi is maintained by a single author. To keep the copyright, licensing, and
product direction unified, pull requests from outside contributors are not
accepted and will be closed automatically.

You are welcome to:

- Use Tachi under the terms of the [AGPL-3.0-only](LICENSE) license.
- Fork the repository for your own personal or internal use, in compliance with
  AGPL-3.0-only.
- Report security vulnerabilities privately by opening a GitHub security
  advisory.

For all other feedback, suggestions, or questions, please use GitHub Discussions
or open an issue. Opening a pull request will trigger an automated close with a
link to this document.
